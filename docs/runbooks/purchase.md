# Runbook: a purchase (complaint → mechanism)

1. **File the complaint** — `CMP-N`, four fields; one recorded harm
   event, never a class argument (CMP-001's ruled defect).
   *Done when:* the file passes the register's sieve (sentence /
   noticed / cost / disposition `open`), numbered from the prefix
   register.
2. **Operator countersigns** — the `bought` disposition names one
   concrete mechanism.
   *Done when:* the disposition line reads `bought <mechanism> (date),
   countersigned by the operator`.
3. **Build minimal** — one mechanism, tier labeled (`client` /
   `engine-dev`), no sibling features smuggled in ("obviously useful"
   is the banned sentence).
   *Done when:* the mechanism exists and does only what the complaint
   bought.
4. **Witness red** — every seeded fault caught; verify the seed itself
   (a broken seed once returned OK and was caught only by expecting
   red — vacuity's birth record).
   *Done when:* each seeded fault's red is reproduced and recorded.
5. **Witness the corpus** — plausible legitimate traffic runs green,
   and the corpus must REPRESENT real traffic: one-family corpora
   missed both the jest collision and the mirror slug bug `[M —
   gate-metrics rows]`.
   *Done when:* the corpus run is recorded with its false-alarm count,
   and the corpus file (if any) is committed.
6. **Birth row** — gate-metrics gains the row: tier, bought-by, both
   witness cells, counts at 0, probation date.
   *Done when:* the row exists and cites the witnesses by date.
7. **Truth sweep** — any sentence in README / architecture / diagrams
   whose truth-value this purchase changed is updated in the same
   commit (rule 12), which may trigger `maintenance-loop.md`.
   *Done when:* `grep` for the old claim finds nothing.
8. **Commit and push** — message through the gate; push on the
   operator's standing or explicit word.
   *Done when:* remote is at the new head and `tl2 check` is green.
