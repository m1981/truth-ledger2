# CMP-020 — mirror's GAP direction is structurally dead in the shipped layout

Sentence:   `tl2 mirror`'s implicit claim that a manifest id cited by
            no test is reported as a GAP. In the real consumer layout
            it is not: the citation scan walks ALL files under the
            root (scripts/tl2, cmd_mirror's os.walk), and the F-2
            convention requires every id to appear inline in its spec
            `.md` — so the spec itself satisfies the scan, and
            deleting a test citation changes nothing. Measured
            (2026-09-01, effectiveness review on kuchnie): fault
            seeded in a stripped mktemp tree → GAP caught; the same
            fault with the spec `.md` present → `mirror clean: 8
            id(s)`. All 36/36 kuchnie manifest ids appear inline in
            their specs, so only the ORPHAN direction is live there.
Noticed:    2026-09-01, by the measured F-1/F-2 effectiveness review —
            not by the birth witnesses, whose fixture had no spec
            `.md` in the tree (the corpus-representativeness lesson, a
            third time: jest, slug-scoping, now this).
Cost:       The direction CMP-005 principally bought ("a spec
            assertion shipped with no test") silently cannot fire on
            the very consumer it was installed for; v1's pilot design
            had already ruled citations live in test files ONLY ("an
            id cited only in conftest.py or a README is invisible to
            the sentinel by design") and the built verb dropped that
            amendment — the second v1 falsification amendment lost in
            the same verb, after slug scoping.
Disposition: bought the citation-scope rule in `tl2 mirror` —
            citations count only from test-shaped files by default
            (`--cite-name` regex, `--cite-all` for the old behavior);
            re-witnessed on a layout-faithful fixture (deleted test
            citation GAPs despite the inline spec id) and on the five
            real consumer manifests (still clean — the discipline
            there was real) (2026-09-01), countersigned by the
            operator
