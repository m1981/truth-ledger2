# Complaints — the register every mechanism must cite

Per constitution C1, this register is the only door mechanisms enter
through. The first gate waits for the first complaint, not the other
way around.

A complaint is one recorded harm event, not a vision and not a feature
request. File `CMP-NNN.md` (numbering per the prefix register) with
exactly four fields:

```
# CMP-NNN — <one line>

Sentence:   the concrete written sentence that stopped being true
Noticed:    when and how the drift was noticed (or that it was not)
Cost:       what the stale sentence cost, as specifically as known
Disposition: open | bought <mechanism> (date) | declined (reason, date)
```

Rules:

- A complaint is append-only: its disposition line changes, its body
  does not.
- Whose harm qualifies: anyone's. A harm event from a client or pilot
  engagement is a first-class complaint, filed the same way — this is
  the only door market demand has into this repository.
- A dated, anchored harm event from another repository's history
  qualifies; an undated "lesson" does not. That difference — event
  with evidence versus interpretation on appeal — is the difference
  between this register and the closed founding currency
  (constitution, "The founding exception is closed").
- One complaint can buy at most one mechanism; a mechanism wanting a
  broader mandate needs more complaints, not a broader reading.
- A `bought` disposition is written or countersigned by the operator,
  never solely by the agent that filed the complaint or wants the
  mechanism.
- A defective complaint is never rewritten (the body is append-only):
  its defect is recorded by an operator ruling appended below the
  body, and the purchase it made stands or falls by that ruling.
- "This would obviously be useful" is not a complaint. That sentence
  built truth-ledger v1's ballast — and at this repository's first
  founding it smuggled an unwitnessed second detector into the first
  gate, where an external reviewer then measured it blocking honest
  English commit messages.
