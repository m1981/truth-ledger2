# Lexicon — the operational vocabulary, queried not read

Status: **DICTIONARY — NON-NORMATIVE.** It names things and justifies
nothing: citing this file is not a purchase currency (constitution C1),
not an argument in a ruling, and never load-bearing — the mechanisms
and law define themselves; this file only lets people talk about them
precisely. Like a map legend, it is queried, never read end to end.

Language note: everything committed in this repository is English
(AGENTS rule 7), but this file is deliberately bilingual — Polish terms
with Polish operational definitions — because it is the operator's
dictionary: the vocabulary as it is actually spoken at the desk. Only
this header is English. Entries are in Polish alphabetical order; a
line with `→ patrz:` is a cross-reference to the entry that holds the
definition.

- **Reader**: anyone needing the precise word.
- **Enables**: operating in this machinery's vocabulary without
  re-deriving it.
- **Update trigger**: a new term enters the machinery or an old one
  changes meaning by ruling.

## Entries

**Adresy D/O** — sesyjne numery wierszy Domknięcia/Otwartych: odpowiadasz adresem, nie cytatem.

**Alarm fatigue / zmęczenie alarmowe** — śmierć narzędzia przez szum: czerwień, którą nauczono się przewijać.

**Aparat** → patrz: Mechanizm vs aparat.

**Atraktor** — zapis przyszłości, do którego nagina się każdą nową obserwację (choroba ratyfikowanych planów).

**Attic** — półka emerytalna dokumentów: poza sweepami, nigdy skasowane.

**Audyt sierot** → patrz: Sierota.

**Autorytet alokacji** — rejestr przydzielający przestrzenie ID przed pierwszym użyciem.

**Balast / ceremonia** — maszyneria bez szkody, która by ją kupiła; koszt bez kupca.

**Bramka (gate)** — sprawdzenie, które umie zablokować (exit ≠ 0); od instrumentu różni się prawem odmowy.

**Brief / intake / proposer** — wzór LLM-owy: mechanika przygotowuje zadanie i bramkuje kształt raportu; osąd proponuje; człowiek dysponuje.

**Catch / miss** — złapanie kontra przepust; rejestr bez missów zawyża każdą bramkę.

**Ceremonia** → patrz: Balast / ceremonia.

**Choreografia / runbook** — proces jako checklista z „done when” przy każdym kroku, pod strażą kapsuły.

**Claim / twierdzenie** — zdanie o repozytorium złożone do rejestru, z pochodzeniem i recepturą dowodu.

**Cytowanie** — ID w pierwszej linii docstringa testu: podpis testu pod obietnicą.

**Czasownik** → patrz: Verb / czasownik.

**Czujka** → patrz: Tripwire / czujka.

**DARK / load-bearing / krawędź przychodząca** — dokument bez wejść / z wejściami; poleganie mierzone linkami, skryptami, kapsułami i łańcuchem bootstrapu.

**Dogfood** — bycie własnym klientem bez prywatnych drzwi.

**Dyspozycja** — los skargi: open / bought / declined.

**Errata** — korekta liczby bez od-kupienia reguły.

**Etykiety [S]/[M]/[I]** — standard / zmierzone / interpretacja, z kotwicą; nieoznaczone domyślnie [I].

**Falsyfikator (klauzula)** — zdarzenie niepasujące do katalogu jest dowodem o katalogu; katalog ustępuje, zdarzenia się nie nagina.

**Fałszywy alarm** — czerwień na niewinnym; waluta, którą bramka płaci za istnienie.

**Fold** — stan jako czysta funkcja nad append-only zapisami; konfluentny = zbieżny po merge'ach.

**GAP / ORPHAN** — obietnica bez testu / test bez obietnicy: dwa kierunki lustra.

**Genom** — komplet kandydatów; legalny tylko jako nieratyfikowane rozumowanie.

**Ground truths** — fakty, na których spec stoi, pod kapsułami zamiast w prozie.

**Instalacja** → patrz: Silnik / instalacja.

**Kanarek** — kontrolowany dowód, że mechanizm umie wykryć/zablokować.

**Kandydat** — zaprojektowany, niekupiony zapis mechaniki; cykl DESIGNED → BOUGHT → BUILT → RETIRED/ABSORBED.

**Kapsuła dowodowa** — zdanie + komenda + hash wyniku + kotwica + obserwowane ścieżki: paragon za zdanie.

**Karta zakresu** → patrz: Scope / karta zakresu.

**Kierunek** → patrz: Memo / kierunek.

**Konstytucja** — reguły wejścia czegokolwiek do systemu (nie treści systemu).

**Korpus** — druga połowa świadka: realny ruch przechodzący zielono.

**Kotwica (anchor)** — commit-świadek: „przy tym stanie świata to było prawdą”.

**Kunktacja** — (Kotarbiński) celowa zwłoka jako sprawność.

**Kupno / waluta zakupu** — jedyna legitymacja mechanizmu: skarga, kontrasygnowana.

**Kwalifikacja narzędzia (DO-330)** — obowiązek dowodu dla narzędzia, któremu ufa się bez sprawdzania — ściślej: którego wynik ma zwalniać z innej weryfikacji (ten warunek DO-330 stawia wprost). Zdanie „LLM-a nie da się kwalifikować" jest wnioskiem tego repozytorium [I], nie zdaniem DO-330 — uzasadnienie: kwalifikacja zakłada narzędzie deterministyczne o ograniczonym zachowaniu, a rozkład wyjść LLM-a nie spełnia żadnej z tych przesłanek.

**Ledger** — append-only rejestr twierdzeń; stan nigdy nie jest przechowywany, zawsze wyliczany z zapisów.

**Limit WIP** — najwyżej jedna specyfikacja w locie; limit zamiast obiecanej daty.

**Lustro (mirror)** — dwie różnice zbiorów manifest↔cytowania.

**Manifest** — goły plik samych ID: maszynowy kontrakt speca.

**Martwe pole (dead zone)** — klasa, dla której mechanizm istnieć nie może; deklarowana, nie przemilczana.

**Martwy kod** — kod bez wymagania; w tym reżimie znalezisko, nie drobiazg.

**Mechanizm vs aparat** — jedna kupiona jednostka wykonawcza kontra całość maszynerii odpowiadającej na jedno pytanie.

**Memo / kierunek** — gatunek, który steruje uwagą i nie kupuje niczego; może się mylić bez łamania czegokolwiek.

**Meta-bramka** — bramka nad bramkami: dowód, że każdy strażnik umie być czerwony (mutuje się aparaturę, nie kod).

**Miss** → patrz: Catch / miss.

**Nagrobek** → patrz: Retrakcja / tombstone / nagrobek.

**Następca** — rekord przejmujący rolę.

**Niezależność (IV&V)** — trzy osie: techniczna, zarządcza, finansowa; klon modelu daje tylko niezależność kontekstu (brak racjonalizacji autora), nigdy niezależność awarii (wspólne ślepe plamki).

**Odmowa (refusal)** → patrz: Scope / karta zakresu.

**Odstępstwo** → patrz: Waiver / odstępstwo.

**Okna bezorzeczeniowe** — czas bez decyzji operatora: legalny na żniwa i konserwację, nigdy na nowe mechanizmy.

**OPEN** — jawnie nazwana dziura decyzyjna: proza, która nie udaje rozstrzygnięcia.

**ORPHAN** → patrz: GAP / ORPHAN.

**Orzeczenie** → patrz: Ruling / orzeczenie.

**Paczka decyzji** — wszystkie pozycje operatorskie naraz, zaadresowane; RULING / JUDGEMENT / SPECIFICATION — rodzaje wg kosztu (zdanie / myśl / sesja).

**Paragon** — zapis szkody przy regule, którą kupiła.

**Partycja** → patrz: Roster vs partycja.

**Pętla konserwacji** — rytuał po edycji obserwowanego źródła: whisper → edycja → commit → następcy → tombstony → check zielony.

**Potencjalizacja** — (Kotarbiński) skutek przez udowodnioną gotowość.

**Powierzchnia publiczna** — jedyny interfejs, przez który także dogfood wolno.

**PPV** — odsetek czerwieni słusznych.

**Prawo** → patrz: Reguła vs prawo.

**Prawo / rozumowanie / choreografie / kierunek / stan** — pięć gatunków dokumentów, różniących się tym, co wolno im zmieniać i jak same się zmieniają.

**Probacja** — data, po której bramka bez trafień umiera własnym rekordem.

**Promocja** — awans zdarzenia z inwentarza do własnego pliku CMP.

**Propriocepcja** — czucie własnych organów: żywotność strażników i rejestrów.

**PROVEN / GREEN-ON-BOTH / INCONCLUSIVE** — trójwartościowy wynik vacuity: dowód / brak informacji / błąd-nie-asercja.

**Proweniencja** — skąd cytat pochodzi i czy wolno mu dźwigać ciężar (verified / unverified here / corrected).

**Ratyfikacja** — orzeczenie czyniące dokument prawem.

**Re-pin** — podniesienie instalacji do nowego taga silnika.

**Recheck** — powtórzenie receptury dowodu i porównanie z zapisanym odciskiem.

**REFER** — odesłanie specyfikacji do własnego slotu.

**Reguła lustra** — każda relacja pilnowana w obie strony.

**Reguła vs prawo** — norma postępowania (AGENTS, wiąże słabo) kontra dokument ratyfikowany orzeczeniem (zmienialny tylko orzeczeniem).

**Rekomputacja** — przeliczaj zamiast księgować: pamięta się tylko to, czego przeliczenie nie odda.

**Retrakcja / tombstone / nagrobek** — wycofanie rekordu z przyczyną, bez kasowania.

**Rodowód (pedigree)** — mapowanie mechanizmu na tradycję, z której pochodzi; nowość = to, co zostaje bez przodka.

**Roster vs partycja** — ręczny spis (gnije cicho) kontra klasyfikacja totalna z wymuszonym „nieprzypisane = błąd” (pada głośno).

**RULING / JUDGEMENT / SPECIFICATION** → patrz: Paczka decyzji.

**Ruling / orzeczenie** — datowany akt operatora.

**Runbook** → patrz: Choreografia / runbook.

**Scope / karta zakresu** — deklaracja granicy spisana z zewnątrz systemu; odmowa (refusal) — jej jednostka: czym system NIE jest.

**Semantyka** → patrz: Syntaktyka vs semantyka.

**Sensorium / zmysły** — kanały percepcji systemu (korespondencja, dotyk, propriocepcja).

**Sentinel / wartownik** — bramka pilnująca jednej relacji (np. spec↔manifest); w v1 zmierzona jako główny szum.

**Sierota** — spostrzeżenie żyjące tylko w rozmowie; audyt sierot — sweep przenoszący je do repo.

**Silnik / instalacja** — kod bezstanowy na tagach kontra kopia narzędzi + lokalny stan w repo, które weryfikuje.

**Sito** — kwalifikacja: konkret+data/kotwica+koszt.

**Skarga (CMP)** — jedno zapisane zdarzenie szkody: zdanie+zauważenie+koszt+dyspozycja; nie wizja i nie klasa.

**Slug** — krótki rdzeń nazwy rodziny ID (cfgapi), przydzielany z rejestru.

**Staff work** — opcje dopracowane do zdania, które wystarczy podpisać; jedno pytanie — nigdy menu.

**Stale** — status zdania, którego dowód przestał się zgadzać; wyliczany, nie nadawany.

**Successor-first** — mechaniczna kolejność pętli: najpierw następca przy nowej kotwicy, potem retrakcja ze wskazaniem.

**Sufit (declared ceiling)** — granica całego aparatu, mówiona na głos: orzeka o formie (korespondencji zapisu), nigdy o treści (wartości pracy).

**Suspect (links)** — status „nie ufaj, aż ktoś spojrzy”: zmiana obiektu flaguje ogniwa na nim stojące.

**Syntaktyka vs semantyka** — cięcie Shannona pod sufitem: mierzalne bez pytania o sens kontra sens, który zostaje ludziom.

**Świadek ciszy** — pusty commit dowodzący, że rozbrojony mechanizm naprawdę milczy.

**Świadek czerwieni** — zasiany błąd widziany czerwonym zanim bramka blokuje.

**Terminacja znalezisk** — każde akcjowalne kończy w: robię / Twoja decyzja / odpuszczam-z-powodem; zero niesklasyfikowanych.

**Tier** — client (wysyłkowe) / engine-dev (domowe, nigdy nie instalowane).

**Tombstone** → patrz: Retrakcja / tombstone / nagrobek.

**Trasowalność dwukierunkowa** — wymaganie↔test↔kod, w obie strony, adresowalnie.

**Tripwire / czujka** — mechaniczne odebranie zaufania zdaniu, gdy zmienia się coś, na czym ono stoi.

**TTL** — zaufanie wygasające z czasem; zegar jako parametr odczytu, nie zapis.

**Twierdzenie** → patrz: Claim / twierdzenie.

**Tworzenie warunków** — (Kotarbiński) właściwy ruch jako najtańszy.

**Verb / czasownik** — jednostka powierzchni CLI, rosnąca wyłącznie zakupami.

**Waiver / odstępstwo** — zarejestrowane, uzasadnione ominięcie bramki; niezarejestrowane = furtka.

**Walidacja** → patrz: Weryfikacja.

**Waluta zakupu** → patrz: Kupno / waluta zakupu.

**Warrant (Toulmin)** — licencja przejścia od danych do tezy; tu: obalany, nie prawdziwy — z warunkami porażki (defeaterami).

**Wartownik** → patrz: Sentinel / wartownik.

**Werdykt** — wynik niezależnej weryfikacji (agree/diverge); nigdy nie bramkuje sam z siebie.

**Weryfikacja** — sprawdzenie, czy zapis odpowiada rzeczywistości. Walidacja — czy rzeczywistość jest tą właściwą. Aparat robi pierwsze, odmawia drugiego.

**Whisper** — wstrzyknięcie „te zdania obserwują to, co zaraz tkniesz” w moment działania.

**Zamrożenie (freeze)** — rejestr przechodzi w archiwum: czytanie tak, zapis nigdy (poza licencjonowanym wyjątkiem).

**Zasiany błąd** — celowo wprowadzony defekt jako pokarm kanarka.

**Zdanie o luce** — „this sentence is the honest record of that gap”: nazwana niewymuszalność zamiast udawanej.

**Zmęczenie alarmowe** → patrz: Alarm fatigue / zmęczenie alarmowe.

**Zmysły** → patrz: Sensorium / zmysły.

**Żniwa (harvest)** — wydobycie zakotwiczonych zdarzeń szkody z historii.
